Базовые Tag Helpers из коробки

| Тег-хелпер/Атрибут                                     | Пример использования                                       | Описание и где применяется                       |                                            |                                        |
| ------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------ | -------------------------------------- |
| `<form asp-action="" asp-controller="" asp-route-...>` | `<form asp-action="Login" asp-controller="Account">`       | Генерирует `<form>` с нужным action и route      |                                            |                                        |
| `<input asp-for="...">`                                | `<input asp-for="UserName" />`                             | Автоматически привязывает поле к свойству модели |                                            |                                        |
| `<select asp-for="" asp-items="">`                     | `<select asp-for="Country" asp-items="Model.Countries" />` | Генерирует выпадающий список на основе данных    |                                            |                                        |
| `<label asp-for="...">`                                | `<label asp-for="Password"></label>`                       | Генерирует `<label>` с правильным for/id         |                                            |                                        |
| `<textarea asp-for="...">`                             | `<textarea asp-for="Comment"></textarea>`                  | Привязывает textarea к свойству модели           |                                            |                                        |
| `<span asp-validation-for="...">`                      | `<span asp-validation-for="Email"></span>`                 | Показывает ошибку валидации для конкретного поля |                                            |                                        |
| \`\<div asp-validation-summary="All                    | ModelOnly                                                  | None">\`                                         | `<div asp-validation-summary="All"></div>` | Показывает список ошибок по всей форме |
| `<a asp-action="" asp-controller="" asp-route-...>`    | `<a asp-action="Details" asp-route-id="5">Link</a>`        | Генерирует `<a href="...">` с нужным маршрутом   |                                            |                                        |
| `<img asp-append-version="true">`                      | `<img src="~/img/logo.png" asp-append-version="true">`     | Добавляет хэш версии к URL для кэш-бастинга      |                                            |                                        |
| `<environment include="" exclude="">`                  | `<environment include="Development">...</environment>`     | Вставляет содержимое только для указанных сред   |                                            |                                        |

Атрибуты маршрутизации
asp-route-имя — добавляет параметры к URL.

<a asp-action="Edit" asp-route-id="123">Edit</a> → <a href="/Controller/Edit/123">

asp-area — указывает Area, если используются модули.

<a asp-area="Admin" asp-controller="Dashboard" asp-action="Index">

Areas
 ├── Admin
 │    ├── Controllers
 │    ├── Views
 │    └── Models
 └── Helpdesk
      ├── Controllers
      ├── Views
      └── Models


Тег-хелперы для ресурсов и статиков

| -------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| `<script src="..." asp-append-version="true">`                 | `<script src="~/js/app.js" asp-append-version="true"></script>` | Добавляет версионирование (для кэширования) |
| `<link rel="stylesheet" href="..." asp-append-version="true">` | Аналогично для CSS                                              |                                             |

| Тег-хелпер                                 | Пример                                              | Описание                               |
| ------------------------------------------ | --------------------------------------------------- | -------------------------------------- |

Специфические хелперы и атрибуты

| Хелпер/Атрибут                                            | Где и как применяется                                    |
| --------------------------------------------------------- | -------------------------------------------------------- |
| `asp-for`                                                 | Привязывает input/select/label к свойству модели         |
| `asp-items`                                               | Используется для `<select>`, список для выпадающего меню |

| `asp-validation-for`                                      | Показывает ошибку для конкретного поля                   |
| `asp-validation-summary`                                  | Список ошибок всей модели                                |
| `asp-append-version`                                      | Для bust cache на статиках (css, js, img)                |
| `asp-antiforgery`                                         | Добавляет/выключает anti-forgery токен в форме           |
| `asp-page`, `asp-page-handler`                            | Для Razor Pages                                          |

Ключевые термины и файлы Tag Helpers

| Ключевое слово/файл   | Для чего/где применяется                                       |
| --------------------- | -------------------------------------------------------------- |
| `_ViewImports.cshtml` | Подключает пространства имен и тег-хелперы для всех view       |
| `@addTagHelper`       | Директива в `_ViewImports.cshtml` для подключения tag-хелперов |
| `@removeTagHelper`    | Удаляет конкретный tag helper из области видимости             |
| Custom Tag Helpers    | Свои классы, наследуемые от `TagHelper`                        |


Tag Helpers — пишутся как обычные HTML-теги с атрибутами asp-*, добавляют логику привязки к модели, роутингу, ресурсам.

Используются для генерации форм, ссылок, labels, ошибок валидации, статических ресурсов и даже условного контента по окружению.

Включаются через _ViewImports.cshtml директивой @addTagHelper.


Общие хелперы

| Хелпер                         | Где и для чего используется                     | Формулировка                                    |
| ------------------------------ | ----------------------------------------------- | ----------------------------------------------- |
| `@Html.ActionLink()`           | Создать ссылку на действие контроллера          | Генерирует `<a>` для перехода на экшн           |
| `@Html.RouteLink()`            | Создать ссылку на маршрут                       | Генерирует `<a>` по имени маршрута              |
| `@Html.BeginForm()`            | Открыть форму для отправки данных               | Открывает `<form>` с указанным экшном           |
| `@Html.EndForm()`              | Закрыть ранее открытую форму                    | Закрывает `<form>`                              |
| `@Html.Partial()`              | Вставить частичное представление (partial view) | Вставляет другую вьюху внутрь текущей           |
| `@Html.RenderPartial()`        | Как Partial, но напрямую пишет в выходной поток | Вставляет вьюху (без возврата строки)           |
| `@Html.Action()`               | Вставить результат выполнения другого экшна     | Вставляет HTML-результат действия контроллера   |
| `@Html.RenderAction()`         | Как Action, но сразу выводит в поток            | Вставляет HTML из другого action (без возврата) |
| `@Html.Raw()`                  | Вставить "сырую" строку (не экранируется)       | Вставляет HTML без encoding                     |
| `@Html.DisplayFor()`           | Вывести значение свойства модели                | Выводит свойство модели, с учетом шаблонов      |
| `@Html.DisplayNameFor()`       | Имя свойства модели (человеко-читаемое)         | Выводит DisplayName атрибут                     |
| `@Html.EditorFor()`            | Генерирует элемент для редактирования свойства  | Создает input/textarea по типу данных           |
| `@Html.Editor()`               | Явно указать имя и тип шаблона редактора        | Выводит редактор для свойства                   |
| `@Html.TextBoxFor()`           | Текстовый input, связанный с моделью            | `<input type="text" ...>` с привязкой           |
| `@Html.TextBox()`              | То же, но с явным указанием имени/значения      | Как выше, без strong-typing                     |
| `@Html.TextAreaFor()`          | Многострочное текстовое поле                    | `<textarea ...>` с привязкой к модели           |
| `@Html.PasswordFor()`          | Поле пароля                                     | `<input type="password" ...>`                   |
| `@Html.HiddenFor()`            | Скрытое поле (hidden input)                     | `<input type="hidden" ...>`                     |
| `@Html.CheckBoxFor()`          | Чекбокс                                         | `<input type="checkbox" ...>`                   |
| `@Html.RadioButtonFor()`       | Радиокнопка                                     | `<input type="radio" ...>`                      |
| `@Html.DropDownListFor()`      | Выпадающий список                               | `<select ...>` связанный с моделью              |
| `@Html.ListBoxFor()`           | Список с множественным выбором                  | `<select multiple ...>`                         |
| `@Html.LabelFor()`             | Подпись к полю                                  | `<label ...>`                                   |
| `@Html.ValidationMessageFor()` | Сообщение валидации                             | Показывает ошибку, если валидация не прошла     |
| `@Html.ValidationSummary()`    | Сводка всех ошибок валидации                    | Отображает список ошибок формы                  |
| `@Html.AntiForgeryToken()`     | Вставить токен защиты от CSRF                   | Скрытый input с токеном                         |


Дополнительные хелперы

| Хелпер                   | Где используется                   | Формулировка                          |
| ------------------------ | ---------------------------------- | ------------------------------------- |
| `@Html.Encode()`         | Экранирование строки для HTML      | Применяет HTML encoding               |
| `@Html.ValueFor()`       | Получить текущее значение свойства | Возвращает value для input            |

Ключевые специфичные термины ASP.NET MVC

| Термин/Ключевое слово | Где/Зачем используется                                  | Формулировка                                                   |
| --------------------- | ------------------------------------------------------- | -------------------------------------------------------------- |
| Controller            | Класс, реализующий бизнес-логику и обработку запросов   | Класс, управляющий поведением и возвратом данных/вью           |
| Action                | Метод контроллера, обрабатывающий HTTP-запрос           | Метод, возвращающий ActionResult                               |
| ActionResult          | Базовый тип результата действия (View, Redirect, Json…) | Объект, который возвращает action-метод                        |
| View                  | Представление, шаблон для вывода данных                 | .cshtml-файл для отображения UI                                |
| PartialView           | Частичное представление, встраиваемое во View           | Локальный reusable шаблон                                      |
| Model                 | Класс с бизнес-данными                                  | Класс данных для передачи между View и Controller              |
| ViewModel             | Класс для передачи данных в/из View, расширяет Model    | Дополнительный слой для нужд конкретного UI                    |
| TempData              | Временное хранилище между запросами                     | Dictionary для передачи данных между action-методами (1 раз)   |
| ViewData              | Dictionary для передачи данных View                     | Передача данных из контроллера в View                          |
| ViewBag               | Dynamic-обертка над ViewData                            | Альтернативный способ передачи данных во View                  |
| Razor                 | Синтаксис разметки для .cshtml                          | Язык шаблонов для представлений                                |
| Layout                | Общий шаблон для всех вью                               | Используется для "рамки" страниц                               |
| Section               | Раздел шаблона, который View может переопределять       | Блок, который вставляется в layout                             |
| Route                 | Маршрут, определяющий сопоставление URL → Action        | Шаблон URL для вызова action                                   |
| Filter                | Атрибуты для расширения действий контроллера            | \[Authorize], \[HandleError], \[ValidateAntiForgeryToken], ... |
| BundleConfig          | Конфиг для склейки и минификации CSS/JS                 | Управление ресурсами фронта                                    |


Жизненный цикл и обработка

| Термин                        | Где используется                            | Формулировка                                            |
| ----------------------------- | ------------------------------------------- | ------------------------------------------------------- |
| Routing                       | Маршрутизация URL                           | Определяет, какой контроллер и action обработают запрос |
| Model Binding                 | Связывание данных                           | Механизм автоматического заполнения модели из запроса   |
| Model Validation              | Валидация модели                            | Проверка свойств модели по атрибутам DataAnnotations    |
| DataAnnotations               | Атрибуты валидации                          | Например, \[Required], \[StringLength], \[Range]        |
| Anti-Forgery                  | Защита от CSRF                              | @Html.AntiForgeryToken и \[ValidateAntiForgeryToken]    |
| Scaffolding                   | Автоматическая генерация кода               | Генерация контроллеров, моделей, view                   |
| Convention over Configuration | Принцип "конвенция вместо конфигурирования" | Имя контроллера = часть URL, action = метод             |


Прочие полезные понятия

| Термин               | Где используется                  | Формулировка                                  |
| -------------------- | --------------------------------- | --------------------------------------------- |
| Tag Helpers          | ASP.NET Core MVC                  | Альтернатива html-хелперам, работают как теги |
| Razor Pages          | Альтернатива MVC в .NET Core      | Страницы с логикой и разметкой вместе         |
| Areas                | Группировка функциональности      | Для разделения приложения на модули           |
| Bundle               | Связка файлов CSS/JS              | Для оптимизации загрузки ресурсов             |
| \_ViewStart.cshtml   | Файл для общего layout            | Автоматически подключается вьюхам             |
| \_ViewImports.cshtml | Подключение namespaces/хелперов   | Для подключения using и TagHelpers            |
| ChildActionOnly      | Атрибут для экшнов только во view | Запрещает вызывать экшн напрямую по URL       |


HTML-хелперы (@Html.TextBoxFor, @Html.ActionLink, и т.д.) — пишутся только в Razor (.cshtml), чтобы рендерить HTML элементы, связанные с моделью.

Контроллеры/Actions — всегда в папке Controllers, отвечают за обработку запросов, возврат представлений и данных.

Модели/ViewModel — классы в Models/ViewModels, используются для передачи/валидации данных между View и Controller.

Filters/Attributes — используются для навешивания логики (авторизация, логирование, обработка ошибок) на action или controller.

Razor, Layout, Partial — для организации и переиспользования UI в .cshtml.

Route/Bundle/Area — для архитектуры и маршрутизации.
